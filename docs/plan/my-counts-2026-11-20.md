# My counts — daily entry in the My4M app (step 1), 2026-11-20

**Goal:** members type their Count Yourself Skinny numbers in the app instead of printing the paper Count Log.
Baseline before work: `pnpm --filter clientportal test` = 7 failed / 287 passed (3 files; env-flaky, ignore).

## Findings
- Live dashboard is `MissionControl.svelte` (`TodayView.svelte` is unmounted legacy).
- Per-day numeric entries already exist: Adherence rows `{date}#{actionId}` with `value` (Float) and `notes` (String); the `measure-*` vitals use them. `weeklyAggregate(..., 'average')` already averages them. No new table, no GraphQL schema change.
- Resolver `recordAdherence.js` has an allow-list of action ids: new ids need a resolver change (CDK deploy). It also lacks `10k-steps` (existing bonus action silently fails today); add it.
- Week anchoring: reuse `programAnchor` / `calendarWeek` / `currentWeekStart` (signup-week, DST-safe `dayDiff`).

## Fields (numeric daily rows of the paper log; 4 inputs)
steps (`count-steps`), average chews per bite (`count-chews`), glasses of water before noon (`count-water`), hours slept last night (`count-sleep`).
Boxes-only rows (walk, light, overnight hours) stay on the existing tape grid / are not daily numbers.
Each row: `value` = number, `notes` = `{"source":"manual"}` (future: `healthkit` | `airpods`, same ids).
